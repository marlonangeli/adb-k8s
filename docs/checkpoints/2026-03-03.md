- Apos `omarchy-restart-terminal`, comandos `kubectl` falharam com `kubectl: command not found`.
- Isso impediu a verificacao do cluster que estava no foco imediato.
- Atualizacao (2026-03-13): acesso funcional confirmado com `mise exec -- kubectl`.

## Proximos passos imediatos

1. Validar acesso ao `kubectl` via `mise`:
   - `mise x kubectl@latest -- kubectl config current-context`
   - `mise x kubectl@latest -- kubectl get nodes -o wide`
   - `mise x kubectl@latest -- kubectl get pods -A`
2. Se o acesso ao cluster estiver ok, seguir para validacao de drift de infra em `infra-oci/oracle-cloud/kubernetes` com `tofu init` e `tofu plan -refresh-only`.
3. Continuar a substituicao progressiva das dependencias bare-metal (MetalLB/Cilium kube-proxy-free) por componentes alinhados ao OKE.
